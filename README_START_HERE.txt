HOW TO OPEN
1. Extract the entire ZIP (don't open index.html inside the archive).
2. Open index.html in Chrome, Edge, Firefox or Safari. All 158 render images are local, no live API needed.
3. Use DARK / COLORFUL at the top right to change the site palette; Ambient Mode is automatic, NOT a separate toggle.
4. Hover on render imagery to see edge-derived Gaussian-blurred halo. On phones, effects are subtler.
5. Click any project: it opens at the TOP; click images for the fullscreen viewer.
6. The brand-logo strip moves continuously from RIGHT to LEFT, and pauses on mouse hover.
